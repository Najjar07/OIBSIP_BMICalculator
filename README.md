# BMI Calculator

This is a simple Python BMI Calculator project developed as part of the Oasis Infobyte Python Programming Internship.

## Project Description

The application takes the user's weight and height as input, calculates the Body Mass Index (BMI), and displays the BMI category.



## Features

* Accepts user weight and height
* Calculates BMI automatically
* Displays BMI value
* Shows BMI category:

  * Underweight
  * Normal weight
  * Overweight
  * Obese


## Technologies Used

* Python


## How to Run the Project

1. Open the project folder in VS Code
2. Open the terminal
3. Run the following command:

python main.py
